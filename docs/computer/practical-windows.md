Windows aur PowerPoint ki Asal Proficiency
Roz ke kaam khud karna seekho

Ye lesson kyun zaroori hai

Bohat se log computer ko saalon istemal karte hain lekin chhote chhote kaamon ke liye dusron ke mohtaj rehte hain. File idhar se udhar karni hai, kisi ko bulao. Screenshot lena hai, mobile se photo kheench lo. Program hang ho gaya, computer band kar do. Ye proficiency nahi hai. Proficiency ye hai ke roz ke ye saare kaam tum khud, sakoon se, baghair ghabraye kar lo.

Is lesson ke do hisse hain. Pehle hisse me Windows ke woh kaam seekhenge jo har roz parte hain. Dusre hisse me PowerPoint me asal presentation banana seekhenge, sirf ye nahi ke slides kesay banti hain, balkay ye bhi ke achhi presentation hoti kesay hai. Dono hisse step by step hain, sath sath karte jao.

Pehla hissa: Windows ke roz ke kaam

Kaam 1: File aur folder banana, naam badalna

Folder woh almari hai jis me tum apni files tartib se rakhte ho. Desktop par ya kisi drive me khaali jagah par right click karo. Jo menu khule us me New par jao, phir Folder par click karo. Aik naya folder ban jayega aur us ka naam neele rang me likhne ke liye tayyar hoga. Wahan apna naam likho, jese Meri Documents, aur Enter dabao. Bas, folder tayyar.

File banana bhi isi menu se hota hai. Right click, New, aur phir jo file chahiye wo chun lo, jese Text Document ya Word Document. File ban jayegi, naam likh kar Enter dabado.

Naam badalna yani rename karna is se bhi asaan hai. File ya folder ko aik dafa click karke select karo, phir keyboard par F2 dabao. Naam likhne ke liye tayyar ho jayega, naya naam likho aur Enter dabao. F2 wali key yaad rakh lo, ye rename ki fix key hai aur paper me bhi ati hai. Aik bareeki, file ka naam badalte waqt us ke aakhir wali extension, jese .docx ya .jpg, ko hath na lagana. Wo badal di to file khulna band ho jayegi, kyunke Windows extension se pehchanta hai ke file kis program ki hai.

Tasveer ka khayal: Is hisse ki diagram me desktop par right click wala menu khula dikhaya jaye, New aur phir Folder par ghaira bana ho, aur sath F2 wali key chhoti si dikhayi jaye.

Kaam 2: Copy paste aur cut paste ka farq

Ye do kaam dekhne me aik jese hain lekin in ka farq na samajhna bohat mehnga parta hai, is liye amal se samjho.

Copy paste ka matlab hai file ki aik naqal dusri jagah banana. Asal file apni jagah rehti hai, dusri jagah us ki copy ajati hai. Tareeqa ye hai. File ko select karo, Ctrl+C dabao. Ab jahan file chahiye wahan jao, us folder ko kholo aur Ctrl+V dabao. File ajayegi. Peeche murr kar dekho, asal file pehli jagah par bhi mojood hai. Ab file do jagah hai.

Cut paste ka matlab hai file ko uthha kar le jana. File ko select karo, Ctrl+X dabao. Dusri jagah ja kar Ctrl+V dabao. File ajayegi, lekin pehli jagah se gayab ho jayegi. Ab file sirf aik jagah hai.

Farq aik jumle me yaad kar lo. Copy me file do jagah hoti hai, cut me file jagah badalti hai. Jab file ki naqal rakhni ho, jese USB me backup lena, to copy karo. Jab file ko tartib se dusre folder me muntaqil karna ho to cut karo. Aur aik aham ehtiyat, cut karne ke baad jab tak paste na kar do, computer band na karna aur dusra cut ya copy na karna, warna file darmiyan me atak sakti hai. Paste karte hi kaam mukammal ho jata hai.

Yehi kaam mouse se bhi hota hai. File par right click karne se Copy aur Cut dono options mil jate hain, aur dusri jagah right click karne se Paste mil jata hai. Keys tez hain, mouse asaan hai, dono seekh lo.

Tasveer ka khayal: Is hisse ki diagram me do shaklein hon — pehli me aik file copy hokar do folders me nazar aye, dusri me wohi file cut hokar pehle folder se gayab aur dusre me mojood ho, aur neeche Ctrl+C, Ctrl+X aur Ctrl+V ki keys dikhayi jayen.

Kaam 3: Delete karna aur Recycle Bin se wapas lana

Jo file nahi chahiye use select karke keyboard par Delete wali key dabao. File gayab ho jayegi. Lekin aik sukoon ki baat sun lo, Delete dabane se file hamesha ke liye khatam nahi hoti. Wo Recycle Bin me jati hai, jo desktop par kachre wali tokri ke nishan se bana hota hai. Ye Windows ki hifazati jaali hai.

Galti se delete ho jaye to ghabrana nahi. Desktop par Recycle Bin kholo. Saari delete shuda files wahan milengi. Apni file par right click karo aur Restore dabao. File apni asal jagah par wapas ajayegi, jahan se delete hui thi bilkul wahan. Aur agar tum chahte ho ke Recycle Bin ki saari files hamesha ke liye khatam ho jayen to Recycle Bin par right click karke Empty Recycle Bin kar do. Us ke baad wapas lana mumkin nahi rehta, is liye ye button soch kar dabana.

Aik aur bareeki bata dun. Agar tum file ko select karke Shift ke sath Delete dabao to file Recycle Bin me nahi jayegi, seedha hamesha ke liye khatam ho jayegi. Ye shortcut taqatwar hai aur khatarnak bhi. Jab tak pakka yakeen na ho, istemal na karna.

Tasveer ka khayal: Is hisse ki diagram me Recycle Bin khula dikhaya jaye, us me delete shuda files nazar ayen, aik file par right click wala menu khula ho aur Restore par ghaira bana ho.

Kaam 4: Screenshot lena

Screenshot matlab screen par jo kuch nazar aa raha hai us ki tasveer. Ye bohat kaam ki cheez hai. Koi error aye to us ka screenshot bhej kar koi bhi tumhari madad kar sakta hai. Koi online payment ki raseed ho to screenshot saboot ban jata hai.

Sab se purana aur asaan tareeqa Print Screen wali key hai. Keyboard par upar wali line me PrtSc likhi key hoti hai. Use aik dafa dabao, poori screen ki tasveer memory me copy ho jayegi, lekin tumhe nazar kuch nahi ayega. Ab Paint ya Word kholo aur Ctrl+V dabao, tasveer ajayegi. Phir use save kar lo. Agar sirf mojooda window ki tasveer chahiye, poori screen ki nahi, to Alt ke sath Print Screen dabao.

Dusra aur behtar tareeqa Snipping Tool hai. Start menu me Snipping Tool likh kar dhundo aur kholo. New wala button dabao, screen halki si dhundli ho jayegi. Ab mouse se wo hissa ghaseet kar select karo jis ki tasveer chahiye. Chhorte hi woh hissa kat kar ajayega. Save wala button daba kar use naam de kar save kar lo. Snipping Tool ka faida ye hai ke tum sirf zaroori hissa lete ho, poori screen ki bheer nahi. Aaj kal ke Windows me Windows key ke sath Shift aur S dabane se bhi yehi kaam foran ho jata hai, ye shortcut khaas yaad rakhne wala hai.

Tasveer ka khayal: Is hisse ki diagram me Snipping Tool khula dikhaya jaye, screen ke aik hisse ke gird ghaseeta hua khana bana nazar aye, aur neeche Print Screen aur Windows+Shift+S ki keys likhi hon.

Kaam 5: File ko zip karna aur kholna

Zip karna matlab files ko dabaa kar aik chhote packet me band karna. Is ke do faide hain. Aik, kai files aik file ban jati hain, bhejna asaan ho jata hai. Dusra, size kam ho jata hai. Email me kai files bhejni hon to zip bana kar bhejna hi aqalmandi hai.

Tareeqa ye hai. Jin files ko zip karna hai un sab ko select karo. Aik se zyada files select karne ke liye pehli file par click karo, phir Ctrl dabaye rakh kar baqi files par aik aik karke click karte jao. Sab select ho jayen to kisi aik par right click karo. Menu me Send to par jao, phir Compressed zipped folder par click karo. Wahi aik zip file ban jayegi. Us ka naam F2 se apni marzi ka rakh lo. Bas, packet tayyar hai.

Zip kholna is se bhi asaan hai. Zip file par right click karo aur Extract All dabao. Aik window khulegi jo puchegi ke files kahan nikaalun, jagah chun kar Extract dabado. Saari files nikal kar aik folder me ajayengi. Aik baat yaad rakho, zip ke andar wali file ko seedha khol kar kaam na karo, pehle extract karo, warna tumhari tabdeeli save nahi hogi aur tum samjhoge ke kaam ho gaya hai.

Tasveer ka khayal: Is hisse ki diagram me right click wala menu dikhaya jaye jis me Send to ke neeche Compressed zipped folder par ghaira bana ho, aur sath aik zip file ka icon bhi dikhaya jaye jis par bandh wali patti bani hoti hai.

Kaam 6: USB lagana aur safely nikalna

USB lagana to sab ko ata hai, lekin use nikalna aksar log ghalat karte hain aur phir kehte hain ke data kharab ho gaya.

USB lagate hi screen par aik paighaam ata hai aur USB aik nayi drive ki shakal me This PC me nazar ane lagti hai. Files copy karna ho to bilkul wese hi karo jese pehle seekha, copy aur paste.

Asal kaam nikalne ka hai. Jab kaam khatam ho jaye to USB ko kheench kar na nikalo. Screen ke neeche dayen kone me, ghari ke paas, aik chhota sa teer hota hai, use dabao to chhupe hue nishan khul jate hain. Un me USB wala nishan milega, us par click karo aur Eject wala option dabao. Jab paighaam aye ke ab nikalna mehfooz hai, tab USB nikalo. Is ki wajah ye hai ke kabhi kabhi Windows peeche file par kaam kar raha hota hai, aur achanak nikalne se wo file aadhi reh jati hai aur kharab ho jati hai. Das second ka ye kaam tumhare mehnat ke data ko bachata hai.

Tasveer ka khayal: Is hisse ki diagram me screen ka neeche dayen wala kona bara karke dikhaya jaye, USB wala nishan aur Eject wala option ghaira bana kar dikhaya jaye, aur sath woh paighaam bhi ho ke ab hardware nikalna mehfooz hai.

Kaam 7: Program install aur uninstall karna

Naya program lagana yani install karna. Program ki setup wali file, jo aam tor par .exe hoti hai, use double click karo. Aik window khulegi, Next dabate jao, shartein ayen to I Agree ya Accept karo, aur aakhir me Install dabado. Kuch dair me program Start menu me ajayega. Aik ehtiyat, program hamesha us ki asal website ya bharose wali jagah se lo. Har chamakti hui website se download karna virus ko dawat dena hai, aur download ke waqt jo fazool izafi programs lagne ki peshkash ho, un ke tick hata dena.

Program hatana yani uninstall karna bhi ana chahiye, warna computer fazool cheezon se bhar jata hai. Settings kholo, Apps me jao. Saare programs ki list ajayegi. Jo program hatana hai use chun kar Uninstall dabao, phir us ki window me Next ya Uninstall dabate jao. Program saaf ho jayega. Program ko us ke folder ko delete karke kabhi na hatao, is se us ki aadhi files computer me reh jati hain aur jaga bhi gherti hain aur maslay bhi banati hain. Sahi tareeqa hamesha Settings se uninstall hai.

Tasveer ka khayal: Is hisse ki diagram me Settings ke Apps wale hisse ki list dikhayi jaye, aik program par Uninstall wala button ghaira bana kar dikhaya jaye.

Kaam 8: Task Manager se hang program band karna

Kabhi kabhi koi program atak jata hai. Mouse ghumta rehta hai, click ka jawab nahi ata, screen par Not Responding likha ajata hai. Aise me aksar log seedha computer ka button daba kar band kar dete hain, jis se khuli files ka data zaya ho jata hai. Sahi tareeqa Task Manager hai.

Keyboard se Ctrl+Shift+Esc dabao. Task Manager khul jayega, jis me chal rahe saare programs ki list hoti hai. Atke hue program ke samne aksar Not Responding likha hota hai. Use select karo aur neeche ya upar End Task wala button dabado. Sirf wohi program band hoga, baqi computer bilkul theek chal raha hoga, aur tumhari dusri files mehfooz rahengi. Phir us program ko dobara khol lo, aksar dobara khulne par woh theek chal parta hai.

Aik aur tareeqa bhi hai, Ctrl+Alt+Delete dabane se aik screen ati hai jahan se bhi Task Manager khulta hai. Lekin Ctrl+Shift+Esc seedha aur tez hai. Ye shortcut apne paas likh kar rakh lo, ye har us din kaam ayega jab computer atak jayega.

Tasveer ka khayal: Is hisse ki diagram me Task Manager ki window dikhayi jaye, aik program ke samne Not Responding likha nazar aye, aur End Task wale button par ghaira bana ho, sath Ctrl+Shift+Esc ki keys bhi dikhayi jayen.

Dusra hissa: PowerPoint me asal presentation banana

Ab presentation seekho. PowerPoint woh app hai jis me tum apni baat bare parde par, slides ki shakal me pesh karte ho. Class me topic samjhana ho, daftar me report deni ho, yehi app kaam ati hai.

Qadam 1: Pehli title slide banana

PowerPoint kholo aur Blank Presentation chun lo. Samne pehli slide ajayegi jis me do khane honge. Upar wale bare khane me apni presentation ka naam likho, jese Pani ki Ahmiyat. Neeche wale chhote khane me apna naam aur class ya ohda likho. Ye title slide hai, ye tumhari presentation ka chehra hai. Is par font bara rakho, taake kamre ke aakhir me bethe shakhs ko bhi parhna ajaye. Agar tayyar design chahiye to Design tab se koi theme chun lo, poori presentation ka rang aur andaaz aik sath badal jayega. Theme shuru me lagana asaan hota hai, baad me lagane se bhi ho jata hai lekin pehle wala sakoon nahi rehta.

Qadam 2: Nayi slides lagana

Ab har topic ke liye alag slide banao. Nayi slide lane ki key Ctrl+M hai, ye yaad kar lo. Ya Home tab se New Slide wala button dabao. Nayi slide aye to us ki shakal bhi soch kar chuno. New Slide ke neeche wale teer se layout milte hain. Jahan sirf heading aur points chahiye wahan Title and Content wala layout lo. Jahan do cheezon ka muqabla karna hai wahan Two Content wala lo, aik taraf aik cheez, dusri taraf dusri. Slide ke bare khane me apna heading likho aur neeche wale khane me apne points likho. Har point alag line par, Enter dabate hi naya point khud ban jayega.

Aik presentation ka dhancha ye rakho. Pehli slide naam wali. Dusri slide aaj ke topics ki list. Phir har topic ki aik ya do slides. Aur aakhir me aik slide shukriya ya sawalat wali. Yahi tartib har achhi presentation ki hoti hai.

Tasveer ka khayal: Is hisse ki diagram me PowerPoint ki window dikhayi jaye, bayen taraf slides ki chhoti chhoti shaklein tartib se lagi hon, beech me title slide khuli ho, aur Ctrl+M ki keys neeche likhi hon.

Qadam 3: Animation lagana — cheezain aik aik karke lana

Animation ka matlab hai slide ke andar wali cheez ko harkat de kar lana. Is ka asal faida ye hai ke tum apne points aik aik karke screen par la sakte ho. Agar saare points aik sath ajayen to sunne wale pehle hi sab parh lete hain aur tumhari baat sunna chhor dete hain. Aik aik karke lane se un ki tawajjo tumhare sath chalti hai.

Tareeqa ye hai. Jis text wale khane ko animate karna hai use select karo. Animations tab par jao. Wahan shuru me hare rang ke sitaron wale options hote hain, ye screen par lane wale effects hain. Un me se Fade ya Appear jesa saada sa effect chun lo. Bas, lag gaya. Ab slideshow me jab tum click karoge to points aik aik karke ayenge. Agar tum chahte ho ke points bilkul aik aik karke ayen, aik click par aik point, to animation wale khane me By Paragraph wala option rehne do, aam tor par wo pehle se set hota hai.

Aik mashwara, animation saada rakho. Har cheez ko ghuma kar, uchhaal kar, teer ki tarah lana presentation ko circus bana deta hai aur asal baat kahin kho jati hai. Professional log aik hi saada effect poori presentation me rakhte hain.

Qadam 4: Transition lagana — slide badalne ka andaaz

Transition animation se alag cheez hai, ye farq pakka kar lo. Animation slide ke andar ki cheez par lagta hai. Transition slide ke badalne par lagta hai, yani jab aik slide ja kar dusri ati hai to darmiyan me jo andaaz banta hai wo transition hai.

Tareeqa ye hai. Bayen taraf se woh slide chun lo jis par transition lagana hai. Transitions tab par jao. Wahan Fade, Push, Morph jese options milenge. Aik chun lo. Agar yehi transition saari slides par lagana hai to Apply To All wala button dabado, har slide par wohi lag jayega. Yehi sahi tareeqa hai, har slide ka alag transition presentation ko be-tartib kar deta hai. Aik hi saada transition, jese Fade, poori presentation ke liye kaafi hai.

Tasveer ka khayal: Is hisse ki diagram me do hisse hon — aik me Animations tab khula ho aur aik text wale khane par effect laga dikhaya jaye, dusre me Transitions tab khula ho aur Apply To All par ghaira bana ho, neeche aik line me dono ka farq likha ho ke animation andar ki cheez par, transition slide badalne par.

Qadam 5: Slideshow chala kar dekhna

Presentation ban gayi, ab use chala kar dekho, bilkul wese jese asal me pesh karoge. Keyboard se F5 dabao. Poori screen par pehli slide ajayegi. Age barhne ke liye mouse click karo, ya space wali key dabao, ya teer wali key. Peeche jana ho to bayen wala teer. Darmiyan me khatam karna ho to Esc dabao, tum wapas apni window me ajayoge. Agar tum chahte ho ke show mojooda slide se shuru ho, pehli se nahi, to Shift ke sath F5 dabao.

Slideshow chalate hue aik cheez khaas dekho. Koi slide par text to zyada nahi ho gaya, koi lafz kinare se kat to nahi raha, rang parhne me aa to raha hai. Jo ghalti tumhe ab nazar ajaye wo use abhi theek kar lo, pesh karte waqt saamne walon ko nazar ayegi aur wahan theek karne ka mauqa nahi hoga. Apni presentation ko aik dafa khud sunne wale ban kar dekhna hi asal proficiency hai.

Achhi presentation ke usool

Ab wo usool jo tumhe aam student se alag karenge. Ye kisi button me nahi milte, ye samajh me milte hain.

Pehla usool, aik slide par kam text. Slide tumhari parchi nahi hai, wo sunne walon ke liye ishara hai. Agar tum ne poora paragraph slide par likh diya to log parhte rahenge, tumhe koi nahi sunega. Slide par sirf bare points likho, tafseel tum apni zubaan se batao. Aik slide par paanch che points se zyada na hon.

Dusra usool, font bara rakho. Heading kam az kam 32 ya 36 ki, aur points kam az kam 24 ke. Jo lafz kamre ke aakhir se na parha jaye, wo slide par hone ka koi faida nahi.

Teesra usool, har cheez tasveer se samjhane ki koshish na karo. Jahan process ya tartib samjhani ho wahan diagram ya saada sa chart zyada kaam karta hai. Aur tasveer wohi lagao jo baat se milti ho, sirf sajawat ke liye lagi tasveer tawajjo bant deti hai.

Chautha usool, rangon ka shor na karo. Aik theme, do ya teen rang, bas. Har slide ka alag rang aur har line ka alag font presentation ko na-parha likha bana deta hai.

Paanchva usool, pehle se mashq. Presentation dene se pehle aik dafa akelay me bol kar dekho. Waqt bhi pata chal jayega aur atakne wali jagahen bhi. Jo shakhs mashq karke jata hai, wo stage par kabhi nahi ghabrata.

Tasveer ka khayal: Is hisse ki diagram me do slides sath sath dikhayi jayen — aik me chhota font aur paragraph bharay hue hon aur us par ghalat ka nishan ho, dusri me bare points aur bara font ho aur us par sahi ka nishan ho, taake farq ankh se zehen me baith jaye.

Aam ghaltiyan jo beginner karta hai

Ab wo ghaltiyan jo main roz dekhta hun, taake tum na karo.

Pehli ghalti, USB kheench kar nikaal lena. Data kharab hone ki sab se aam wajah yehi hai. Hamesha Eject karke nikalo.

Dusri ghalti, file ka naam badalte hue extension mita dena. Us ke baad file kisi program me nahi khulti aur log samajhte hain ke file kharab ho gayi.

Teesri ghalti, program hang hone par seedha computer band kar dena. Pehle Task Manager se sirf wohi program band karo, baqi kaam bach jayega.

Chauthi ghalti, zip ke andar hi file khol kar kaam karna aur phir tabdeeli ka gayab ho jana. Hamesha pehle extract karo.

Paanchvi ghalti, presentation ki har slide par paragraph bhar dena aur chhota font rakhna. Sunne wale parh bhi nahi sakte aur sun bhi nahi sakte.

Chhati ghalti, har slide par alag animation aur alag transition lagana. Presentation maloomat ki jagah tamasha ban jati hai. Saadgi hi professional pehchan hai.

Khud kar ke dekho

Ab ye mashq khud karo, dono hisso ki. Pehle Windows wali. Desktop par apne naam ka folder banao, us ke andar aik text file banao aur us ka naam F2 se badal kar Meri File rakho. Phir us file ko copy karke dusre folder me rakho, aur asal wali ko cut karke pehle folder se hata kar dekho ke copy aur cut ka farq ankh se nazar aye. Phir koi file delete karke Recycle Bin se restore karo. Apni screen ka aik screenshot Snipping Tool se lo aur save karo. Apni do files ko zip banao aur phir extract karke dekho. Aur Task Manager khol kar dekho ke is waqt kaun kaun se program chal rahe hain, band koi na karna, sirf pehchano.

Phir PowerPoint wali mashq. Apne pasandida topic par paanch slides ki presentation banao. Pehli title slide, dusri topics ki list, do slides asal maloomat ki, aakhri sawalat wali. Aik theme lagao, points par saada animation lagao, saari slides par aik hi transition lagao. Phir F5 daba kar poora show chalao aur sunne wale ki nazar se dekho. Agar dono mashqain tum ne kar lin to samajh lo ke computer tumhare liye ajnabi nahi raha, tum us ke asal malik ban gaye ho. Yahi woh proficiency hai jo paper se bahar ki zindagi me kaam ati hai.
